# 기본 조작

- 이동: WASD
- 점프: Space
- 조준: 마우스
- 발사: 좌클릭
- 가드: 우클릭 또는 Shift

---

# 핵심 시스템

## 1. 총 시스템

### 기본
- 마우스 방향으로 발사
- 총알은 물리 판정 사용

### 특징
- 자신의 총알에도 피해 가능
- 폭발 피해 자가 피격 가능
- 도탄 시 자기 자신 피격 가능

### 총알 속성
- 데미지
- 속도
- 크기
- 넉백
- 반사 횟수
- 폭발 여부
- 상태이상

---

## 2. 가드 시스템

### 기본 가드
- 짧은 시간 공격 방어
- 쿨타임 존재

### 가드 효과
- 총알 방어
- 일부 총알 반사
- 카드 효과 발동 가능

### 가드 카드 예시
- 폭파 방어
- 충격 방어
- 반사 신경
- 생존 본능

---

## 3. 카드 시스템

### 카드 선택
- 라운드 패배 시
- 카드 5개 랜덤 등장
- 1개 선택 가능

### 카드 구조
- 장점 1개
- 단점 1개

### 예시
#### 광전사
- 장점: 공격력 증가
- 단점: 최대 체력 감소

---

## 카드 종류

### 공격 카드

- 폭파광

## 4. 빌드 시스템

### 빌드 추천 표시
플레이어 카드 조합 기반 추천 제공

### 예시
- 폭격수
- 넉백 빌드
- 요새 빌드
- 유리대포 빌드

### 빌드 UI
- [폭발]
- [가드]
- [넉백]
- [이동]

### 빌드 시너지
- 특정 카드 조합 시 특별 이름 출력
- 추가 이펙트 가능

### 예시
- 핀볼 폭격
- 철벽 요새
- 맹독 추적자
